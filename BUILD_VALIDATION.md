# Build validation checklist

The automated workflow compiles the Android debug APK and runs 3,000 puzzle-generator checks before publishing an APK artifact.

Before a Play Store launch: validate Android rendering/touch targets on a physical device, test opt-in AdMob rewarded hints, replace all test AdMob IDs with approved production IDs, sign a release AAB, and complete the Play Console declarations.

This prototype does **not** yet provide real-money Google Play Billing.
